# Anti-slop checklist

Any hit is a FAIL. The design-critic reports every hit; the task is not done until
there are none.

1. No purple-to-blue gradients. No gradient text.
2. No frosted-glass cards as the default surface.
3. Not Inter, Roboto or system fonts alone. A visible hierarchy: display, text, tabular figures.
4. No centred hero + three feature cards + call-to-action template.
5. No emoji as icons. No unstyled stock icon set.
6. Not every element rounded with the same drop shadow.
7. No filler words: unleash, revolutionize, seamless, elevate, AI-powered, next-level, cutting-edge.
8. No decorative blobs, particles or gradients that mean nothing.
9. No fade-up-on-scroll applied to everything.
10. No near-black page with neon accents as the dark mode.
11. No loading spinner. Loading shows the atoll being built.
12. No number on the site that is not from `results/`, and every win rate names its table size.

## What good looks like here

- The world is the hero; the HUD hugs the edges.
- Interface lives in the world where it can: prices on signboards, cash in a ledger,
  auctions in the market square.
- 2D panels look like objects from the island (paper, sailcloth, brass), not glass.
- One primary action per decision panel; everything else visibly secondary.
- Every animation explains something: a hop, travelling coins, a building rising.
- `prefers-reduced-motion` swaps travel for fades.
